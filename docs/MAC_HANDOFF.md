# macOS 适配／测试交接

已加入独立的 macOS Swift 测试实现（`macos/Meter.swift`）；Windows ZIP 仍不能在 Mac 上运行，也不能把本地测试版宣称为正式发布。

## 第一阶段：只读可行性检查

需要真实 Mac，安装并登录 WorkBuddy。记录 macOS 与 WorkBuddy 版本、Apple Silicon／Intel 和显示缩放。另一个账号／对话本身不能代替 Mac 环境。

先验证以下条件，不修改 WorkBuddy 安装文件，不关闭正在进行的用户任务：

1. Mac 客户端是否允许自身 Electron 运行时执行只读取数助手；Windows 原生绑定未必存在。
2. 登录态的位置及安全存储方式，是否与 Windows 完全不同。只报告字段形状和是否可用，绝不要输出、提交或传输令牌、密钥和完整登录态。
3. 优先查找客户端提供的安全、受支持读取方式。任何钥匙串／辅助功能／屏幕录制权限由用户自己确认，不绕过权限。
4. 只请求当前用户自己的官方计费接口；不可把国内版可用推断为国际版可用。

## 第二阶段：另写 Mac 窗口层

- Windows 的 ctypes/user32 层不能复用。需要设计原生 macOS 面板及窗口跟随方式。
- 验证移动、缩放、最小化、退出重开、失去焦点、Spaces、全屏、Stage Manager、外接屏与 Retina 缩放；特别确认不覆盖系统窗口按钮。
- 当前用户自启、关闭自启、完整卸载都需单独适配与说明。
- 权限不足时明确提示并停止，不浮在其他应用上，不伪装成已附着。

## 2026-10-15 实测进度

- macOS 26.6.2 / Apple Silicon；国内版 `/Applications/WorkBuddy.app` 5.8.2（`com.tencent.workbuddy.mac`），国际版 `/Applications/WorkBuddy AI.app` 5.7.6（`com.workbuddy.workbuddy-ai`）。
- 两个 Electron 客户端均支持 node 模式及只读原生绑定；两份登录态位于 `~/Library/Application Support/CodeBuddyExtension/Data/Public/auth/`。没有记录或提交任何令牌／账户内容。
- 两版本分别使用各自运行时读取自己的登录态，只向对应官方计费域名请求；两次取数结果均 `ok:true`。未向此文档写入实际积分值。
- Swift 客户端构建和核心布局自检通过，`dist/workbuddy-titlebar-meter-macos-arm64.zip` 仅为本地测试包。未变更两个已安装的 WorkBuddy 包；未自动设置登录自启。
- 10 月 15 日在 `~/Applications/WorkBuddy Titlebar Meter.app` 安装本地副本，额外安装 `~/Applications/Start-Meter.command` 启动入口；以两版本作为前台分别测得 210×26 面板显示于对应标题栏，切换前台时仅一条可见。没有启用登录自启；会话测试结束后停止测试进程。
- 同日修正位置与显示条件。依据用户截图（1x，裁剪起点 x=1582）逐像素测得：面板原在全局 x=1690–1899，标题栏按钮簇占 x=1743–1899（最右约 177pt），纵向 y=51–65，面板纵向 35–61，因此面板几乎整块压住按钮。现改为面板右缘距窗口右边 190pt（`Placement.buttonReserve`），实测国内版窗口面板位于 x=1520–1730、国际版位于 x=547–757，与按钮留有约 13pt 间隔。
- 显示条件由“仅前台客户端”改为“宿主窗口在屏即显示”，默认两条积分条可同时可见，右键菜单可切回仅前台显示；已实测在无客户端前台时两条面板同时存在。
- 随后取得屏幕录制权限，用 `screencapture` 直接复核，发现前一步的测量把两处混为一谈并推翻两个常量：
  - 纵向：面板在窗口 y=5–30，而标题行（文字与图标）国内版在 y=24–39、国际版在 y=20–35，面板整体偏高 10–14pt。
  - 横向：两版标题栏按钮数量不同。国内版 5.8.2 只有 3 个按钮，最左按钮距窗口右边 111pt；国际版 5.7.6 有 5 个，距右边 179pt。单一固定值必然一端过紧一端过松。
  - 颜色：面板底色 `#1f1f21` 比标题栏实测 `#141414` 浅，看起来像贴了块补丁。
  - 现改为按版本分别取常量：`buttonReserve` = 111/179 + 18pt 间隔，`titleRowCentre` = 31.5/27.5，底色改用 `#141414`。实测国内版面板窗口内 x=633–843、国际版 x=540–750，纵向中心分别 32 与 28，与标题行中心（31.5/27.5）误差 ≤0.5pt，两端按钮前均留 18pt。
- 环境限制与经验：`CGWindowListCopyWindowInfo` 无需权限即可读窗口几何，但窗口截图（`screencapture -l`）不含覆盖其上的其他窗口，需用区域截图 `-R`；未授权时可用用户提供的截图离线逐像素分析（本机屏幕为 1x）。`open -n` 启动本应用在此环境失效，直接执行 `.../Contents/MacOS/meter` 或 `Start-Meter.command` 可用。
- 待人工确认：窗口移动／缩放／最小化／重启、Spaces／全屏／Stage Manager／外接屏／Retina，以及客户端改版后按钮数量变化时的间隔；正式分发前还需开发者签名、公证。

## 发布决定与仍存限制

用户于 2026-10-15 确认按当前 macOS 26 开发成果发布测试包，暂不降低系统版本。v0.2.0 将该 ARM64 包原样发布并标为 **macOS 26+ 测试版、未签名／未公证**；这不代表上方待人工确认的生命周期场景已完成测试。Windows 发布端只核对包结构、架构、最低系统与校验值，不代替 Mac 实机测试。
